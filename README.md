# 账单合并统计工具

一个纯本地的单文件网页工具：把**微信支付**和**支付宝**导出的账单合并到一起，统计你的整体消费结构。

## 在线使用

部署在 GitHub Pages 上：**https://nexor-source.github.io/expense-tracker/**

## 功能

- 拖入微信 / 支付宝导出的 CSV / XLSX 账单（自动识别 GBK / UTF-8 编码、自动识别平台与新旧表头）
- 两平台合并、按交易单号自动去重
- 591 条内置关键词规则自动分类（餐饮 / 交通 / 日用购物等 17 类），可手动调整并记住
- 分类占比、月度趋势、微信 vs 支付宝对比、商户 Top 20
- 退款自动处理（部分退款按净额、全额退款不计入）、支持导出明细与汇总 CSV

## 隐私说明

**所有数据只在你的浏览器里处理，不上传、不联网、不落任何服务器。**
本仓库只有工具代码，不含任何个人账单数据。

## 账单导出方法

- 微信：我 → 服务 → 钱包 → 账单 → 常见问题 → 下载账单 → 用于个人对账
- 支付宝：我的 → 账单 → 右上角 ··· → 开具交易流水证明 → 用于个人对账

导出的压缩包会发到邮箱，解压密码见平台通知，**解压后**把里面的文件拖进工具即可。

## 技术

零依赖单 HTML 文件，纯原生 JavaScript，自带 XLSX / ZIP 解析（含 Excel 序列日期识别、多编码识别）。
