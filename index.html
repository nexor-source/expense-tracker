9. 分类规则 自动识别的依据，你可以随时改

规则按从上到下的顺序匹配：某笔交易的「交易对方 + 商品 + 类型」里包含关键词，就归到对应分类。越具体的规则越应该排在前面。

10. 怎么把账单导出来

微信支付

  1. 手机微信 → 我 → 服务 → 钱包 → 账单
  2. 右上角 常见问题 → 下载账单
  3. 用途选 「用于个人对账」（选“用做证明材料”给的是 PDF，读不了）
  4. 选时间范围（最长 1 年）→ 填邮箱 → 输入支付密码
  5. 邮箱收到压缩包，解压密码在微信「服务通知」里
  6. 解压出 CSV 或 XLSX，拖进本工具即可
电脑版更快：微信电脑版左下角 ··· → 设置 → 通用设置 → 账单与交易 → 导出账单，直接得到 CSV。

支付宝

  1. 手机支付宝 → 我的 → 账单
  2. 右上角 ··· → 开具交易流水证明
  3. 用途选 「用于个人对账」
  4. 选时间范围（最长 1 年，建议按年导出）→ 填邮箱 → 验证身份
  5. 邮箱收到压缩包，密码在支付宝「服务通知」或该功能的申请记录里（一般是身份证后 6 位）
  6. 解压出 CSV，拖进本工具即可
官网也行：支付宝网页版 → 交易记录 → 下载账单，可导出 CSV。
几个容易踩的点
· 邮箱里的压缩包有密码，本工具不能直接读加密压缩包，请先用系统自带解压或 7-Zip / Bandizip 解压，再把里面的 CSV / XLSX 拖进来。
· 微信的收/支列会出现「不计入收支」（充值、提现、信用卡还款、理财通等），这些默认不参与消费统计，是正常的。
· 已退款、部分退款的交易会自动按净额计算（全额退款的那笔不计入支出）。
· 两个平台导出范围重叠时，程序会按交易单号自动去重，导入完会提示去重了几笔。
数据只在你本机浏览器内存中处理，关闭页面即消失；本工具不联网、不上传任何内容。分类规则存在浏览器本地，下次打开还在。
